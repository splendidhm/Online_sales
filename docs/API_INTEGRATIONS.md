## 가정과 실계정 확인 순서

초기 가정은 대표자가 수동 확인한 도매 증빙과 경쟁 표본으로 소량 운영할 수 있다는 것이다. 공급사의 재판매 허용과 이미지 사용·편집 허용은 별도 항목이다. 각 계정의 정확한 호출 한도, 상업 데이터 재사용 권한, 샌드박스 제공 범위에 공통값을 두지 않는다.

개인사업자 등록 상태와 통신판매업 신고 해당 여부를 확인한다. 공급처 계정 → 스마트스토어 → 쿠팡 → G마켓 심사 순으로 준비한다. 허용 IP와 서버 측 비밀 저장소를 설정한 후 읽기 권한부터 시험한다. 실상품 쓰기 시험은 3단계에서 대표자가 최종 승인한 게시본으로 진행한다. 호출 일시·권한 범위·외부 ID·조회 결과를 남겨 ‘실계정 확인’으로 갱신한다. [정부24 통신판매업 신고](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=11300000006)
