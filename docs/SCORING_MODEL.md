# 상품 가격·경쟁강도·추천 기준

## 주문 1건, 채널 1곳, 옵션 1개의 손익

입력은 승인 전 표에 모두 표시한다. P는 상품 판매가, S는 구매자 부담 배송비, D는 판매자 부담 할인, R은 판매자가 인식하는 주문 수익(P + S − D)이다. 플랫폼 부담 할인은 정산상 판매자 부담분이 확인될 때만 비용에 반영한다. 공급원가 C는 판매 구성 수량 전체의 금액이다.

| 출력 | 계산 |
|---|---|
| 매출총이익 | R − C |
| 예상 공헌이익 | R − C − 공급사 배송비 − 포장·처리비 − 채널·결제 수수료 − 주문당 광고비 − 예상 반품·취소 손실 |
| 예상 공헌이익률 | 공헌이익 ÷ R × 100. R이 0 이하인 시나리오는 계산 불가 |
| 기간 영업이익 | 해당 기간 실현 공헌이익 합계 − 기간 고정비 |
| 세금·세후소득 | 납부세액과 대표자 세후소득은 과세유형·기간 자료와 별도 가정이 확보된 시나리오에서만 추정 |

수수료 기준 금액(상품가·배송비·할인)과 반올림은 채널 계약별로 버전 관리한다. 결제 수수료가 이미 포함된 경우 중복 차감하지 않는다. 반품·취소는 사건별 발생 확률 × 회수 불가능한 순손실을 합산하며 중복 사건을 한 번만 반영한다. 실현 공헌이익에는 실제 정산 수수료·조정액·환불·반품 비용을 적용하고 이미 포함된 예상 비용을 대체한다.

초기 비교는 모든 항목을 부가세 포함 현금 기준으로 통일해 ‘세액 정산 전 예상’으로 표시한다. 별도 기준을 선택하면 입력 항목별 과세 여부와 근거에 따라 같은 기준으로 환산한다. 근거가 없는 혼합 기준은 계산 보류다. 판매가 표시는 원 단위, 내부 금액·비율은 Decimal로 보존하며 화면 비율은 소수 첫째 자리까지 표시한다.

## 최저가와 추천가

1. 대표자가 비용표와 목표 공헌이익률을 입력한다. 미설정 비용은 ‘미입력’이다. 0원은 대표자가 명시할 수 있다. 판매 가능한 가격 단위에서 동일 계산 함수를 평가해 공헌이익 ≥ 0인 최저가(손익분기), 목표 이익률과 공급사 판매준수가격 조건을 모두 만족하는 최저가(최소 판매가)를 구한다. 공급사 기준의 배송비 포함 여부를 명시한다.
2. 채널·옵션당 최근 확인한 서로 다른 판매자 최대 5곳을 사용한다. 판매자별 최근 1건, 중복 링크 제외, 동일 구성·규격·수량과 통상 구매자가 이용 가능한 배송 조건을 확인한다. 회원 쿠폰·조건부 가격, 불명 배송비, 불일치 규격은 비교에서 제외한다. 조사 스냅숏에는 제외 사유와 시각을 저장한다.
3. 유효 표본 5건의 배송포함가에 대해 범위와 중앙값을 산출한다. 추천 상품가는 비교 중앙값에서 우리 배송비를 차감하고 승인할 판매자 할인을 되더한 뒤 허용 가격 단위로 내림한다. 최소 판매가와 대조한다. 목표 마진을 달성하기 어려우면 최소 판매가와 시장 기준의 차액을 표시하고 보류를 제안한다.
4. **가격 경쟁강도**는 우리 최소 판매가의 구매자 실부담 총액 이하인 표본 수로 판정한다. 0~1곳은 낮음, 2~3곳은 보통, 4~5곳은 높음이다. 5건 미만은 ‘비교 자료 부족’으로 반환한다. 표본이 충분해도 판매량·시장 전체 점유율은 미확인이다.
5. 공급가 10% 상승, 광고비 1,000원 증가, 비교 중앙값 5% 하락을 각각 독립 적용해 이익·최저가·보류 여부의 변화를 표시한다. 수치는 초기 민감도 가정으로 편집할 수 있다.

## 근거와 점수

필수 조건(판매 가능 여부, 1개 직배송, 재고, 권리, 비용, 비교 근거)을 먼저 검사한다. 부적격은 제외, 보완 가능하면 보류한다. 음수 이익 또는 목표 마진 미달은 자동 추천에서 제외하고 사유를 표시한다. 1차 승인 대상은 게이트를 통과한 채널이다.

초기 평가 구성은 수익성 30%, 수요 25%, 가격 경쟁력 20%, 공급사 신뢰도 15%, 차별성 10%다. 각 항목은 0~100점이다. 수익성은 목표 미달 0, 목표 이상 70, 목표보다 5%p 이상 높으면 100이다. 경쟁력은 경쟁강도 낮음·보통·높음에 각각 100·60·20을 부여한다. 수요·공급 신뢰·차별성은 근거가 있는 평가에 한해 대표자가 낮음·보통·높음(20·60·100)과 사유를 기록한다. 인정 근거는 확인된 주문 추세, 공급 이행 기록, 비교 표본에 없는 검증된 구성 등이다.

모든 항목이 관측되면 가중 합계를 계산한다. 결측 시 총점은 ‘평가 보류’, 자료 신뢰도 지표는 **근거를 확인한 항목의 가중치 합(%)**으로 별도 표시한다. 이는 자료 충족률이다. 필수 조건을 통과했으면 총점 없이도 수동 상품성 판단이 가능하다. 자동 추천은 완전한 점수만 총점 내림차순으로 선정하고 동점은 예상 공헌이익, 공급 상품번호 순이다. 평가 기준과 가중치는 버전을 저장한다.

## 검산 사례

무료배송 14,900원, 공급가 6,000원, 공급사 배송비 3,000원, 수수료 1,490원, 반품·광고비 합계 900원, 나머지 0원 → 공헌이익 **3,510원**, 이익률 **23.6%**. 같은 조건에서 공급가만 10% 상승하면 **2,910원**, **19.5%**다. 예시 수수료는 실제 마켓 계약값과 구분한다.
