# 시장조사 기반 판매가와 주문당 예상 이익

같은 마켓에서 제조사·모델·구성이 같은 표본을 먼저 사용한다. 같은 상품이 없으면 품목·규격·구성 검색어가 모두 들어가고 구성과 배송 조건 비교가 가능한 표본을 리뷰 수 내림차순으로 정렬한다. 기본 상위 5개, 선택 시 10개다. 중복 링크는 최근 관측을 사용한다. 리뷰 수는 유사 상품의 표본 선정에 사용한다.

채택 표본의 배송포함 중앙값에서 구매자 배송비를 빼고 공급사의 상품가 준수 조건을 반영해 제안 판매가를 구한다. 예상 이익은 제안 판매가와 구매자 배송비의 합에서 구성 전체 매입가, 조건 적용 후 공급 배송비, 마켓 수수료를 차감한 금액이다. 이익률의 분모는 구매자 배송비 포함 수입이다. 포장·광고·반품 비용은 이 지표의 범위 밖이다. 표본 수와 근거를 함께 보고 대표자가 진행·보류·제외를 결정한다. 이익률 하한은 없다.

수수료 표 확인일은 2026-11-11이다. 스마트스토어는 일반 쇼핑 유입과 선택한 Npay 매출 등급, 쿠팡은 지원하는 세부 분류의 VAT 포함 예상액을 사용한다. 쿠팡 유료 배송 수수료 또는 미지원 분류는 확인 대기다. 기존 계산서의 저장된 평가·결정은 과거 버전으로 유지하고 새 평가는 시장 가격 기준으로 저장한다. ## 상품성 평가 v1

수익성 30%, 수요 25%, 가격 경쟁력 20%, 공급사 신뢰도 15%, 차별성 10%를 적용한다. 수익성 점수는 예상 이익률의 백분율 값을 0~100점 범위로 제한한다. 가격과 진행 승인에는 이 점수를 사용하지 않는다.

가격 경쟁력은 가격 결정에 채택한 표본 중 서로 다른 판매자 3곳 이상일 때 평가한다. 같은 판매자는 최저 배송포함가 한 건으로 집계한다. 제안가의 구매자 실부담액보다 5% 이상 저렴한 판매자 비율이 1/3 미만이면 경쟁강도 낮음, 2/3 미만이면 보통, 그 이상이면 높음이다. 가격 경쟁력 점수는 (1 − 해당 비율) × 100이다. 이는 표본 기준의 초기 추정이다.

수요·신뢰도·차별성은 대표자가 입력한 등급(낮음 20점, 보통 60점, 높음 100점)과 근거를 함께 저장한다. 근거 충족률은 평가 가능한 항목 가중치의 합이다. 다섯 항목이 모두 채워지면 가중평균을 반올림해 종합 점수를 표시한다. 서버가 각 저장 버전에 점수와 근거를 함께 기록한다.

## 허가된 검색 공급처 연결

서버 환경변수 `ACC_RESEARCH_URL`에 계약한 공급처 어댑터의 HTTPS 주소를 설정한다. 필요한 경우 `ACC_RESEARCH_TOKEN`을 사용한다. 서버는 GET 요청에 channel(네이버·쿠팡), q, kind(exact·similar), sort(relevance·reviews_desc)를 보낸다. 응답은 동일 channel과 items 배열이다. 표본마다 title, maker, model, option, seller, url, reviews, price, shipping, time(한국시간 YYYY-MM-DDTHH:mm), match(일반 배송·구성 비교 가능 여부)를 전달한다. 공급처가 없으면 두 검색 링크와 직접 입력을 사용한다. 자동 수수료는 위 출처에서 확인해 코드에 반영한 버전이며 공급처의 상품 검색 응답에서 요율을 가져오지 않는다.
