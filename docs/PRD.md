# 제품 요구사항

## 운영 목표

대표자 한 명이 성인용 비전기 수납·사무 소품을 무재고 위탁판매한다. 하루 업무는 조사할 후보 확인, 상품성 판단, 상세페이지 검수, 등록 예외 처리 순이다. 첫 현장 검증은 상품 한 개의 조건·원가·경쟁가를 직접 확인해 판매 여부를 결정하는 일이다.

## 후보에서 등록까지

1. 도매매 1개 직배송 상품을 우선한다. 도매꾹도 동일 조건을 확인한 상품만 포함한다. 회차당 원천 후보는 최대 1,000개다. 중복, 품절, 최소 주문량, 판매 가능 채널, 이미지 사용 조건과 공급사 판매준수가격을 확인한다. 권리·필수정보 미확인은 보완함에 모은다.
2. 시범 회차에서는 필터 통과 상품 중 최대 10개를 조사한다. 공급가·배송비 확인, 중복 없는 규격·옵션 식별이 가능한 상품을 우선하고 동순위는 공급 상품번호순으로 고른다. 네이버·쿠팡별로 검색어를 제공하고 대표자가 실물과 비교 가능한 판매 표본을 직접 기록한다. 운영 확대 시 최종 추천은 최대 30개다. 회차별 권장 규모는 20~30개이며 기준을 충족한 상품이 없으면 0개로 마감한다.
3. 1차 승인 화면에는 제품·공급사·옵션, 공급단가, 제반 비용, 시장 가격대, 추천가, 예상 공헌이익과 이익률, 경쟁강도, 자료 신뢰도, 공급사 신뢰 근거, 확인 시각과 위험 요인을 표시한다. 대표자는 채널별로 진행·보류·제외를 선택한다.
4. 승인된 상품에 한해 권한 있는 사진과 원문으로 상세페이지를 만든다. 작성 결과를 별도 검수 단계에서 원본과 대조한다. 누락된 원산지·인증·치수는 보완 요청하고 근거 없는 광고 문구는 삭제 또는 수정안을 제시한다.
5. 2차 승인 화면에서 채널별 이미지·본문·필수고시·옵션·가격·배송비·재고와 수정 전후를 확인한다. 대표자는 게시 승인·수정 요청·제외 중 선택한다. 게시 완료 후 등록번호로 다시 조회한다.
6. 결과 보고는 상품·채널별 한 줄이다. 상품명, 옵션, 공급단가, 승인 판매가, 등록가, 예상 공헌이익률, 표본 기반 경쟁강도, 성공·실패·대기·불일치, 실패 원인과 확인 시각을 표시한다. 상단 건수는 채널 등록 건 기준으로 합산한다.

## 화면과 출시 범위

| 단계 | 화면 | 완료 시 대표자가 할 수 있는 일 |
|---|---|---|
| 1 | 운영 현황, 수집 회차, 후보 탐색, 시장조사 상세, 상품 점수·수익성, 승인 대기함 | 시험 데이터로 연습하고 직접 입력한 실자료로 1차 승인까지 처리 |
| 2 | 상세페이지 편집, 품질 검수, 승인 대기함의 게시 탭 | 마켓별 미리보기, 수정안 비교, 최종 승인과 자료 내보내기 |
| 3 | 마켓 등록 현황, 연동 설정, 감사 이력 조회 | 스마트스토어부터 등록 검증, 쿠팡 추가, G마켓 승인 시 연결 |
| 4 | 가격·재고 알림, 주문·정산, 수익 분석 | 공급가·재고 변화 확인, 실현 이익 대조, 일간 경고·주간 보고 |

초기 주문 발주·환불·배송 대응은 대표자가 판매자센터에서 처리한다. 실주문 정보 처리는 4단계에 도입한다. G마켓 권한 대기 중에는 검수 완료 자료를 내보내고 대표자가 수동 등록 결과를 별도로 기록한다.
